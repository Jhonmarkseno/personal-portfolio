# Jhon Mark C. Seno — Personal Portfolio

A responsive, single-page personal portfolio for **Jhon Mark C. Seno**, a BSIT student and aspiring web developer. The design uses a "liquid glass" aesthetic with gradient accents, scroll-reveal animations, and a scroll progress indicator.

**Live URL:** https://jhonmarkseno.github.io/personal-portfolio/

## Overview

The site presents a short introduction, skills and technologies, selected projects, education and experience, and contact information. It is built with plain HTML, CSS, and JavaScript — no framework or build step required.

## Technologies

- HTML5
- CSS3 (custom properties, Grid, Flexbox, backdrop-filter glass effects)
- Vanilla JavaScript (ES6)
- Google Fonts (DM Sans, Space Grotesk)

## Features

- Fully responsive layout for mobile, tablet, and desktop
- Liquid-glass cards with hover lift effects
- Animated gradient text and background
- Scroll-reveal transitions with staggered timing
- Top scroll-progress bar
- Mobile navigation menu with active-section highlighting
- One-click email copy button
- Smooth section navigation with fade transitions
- Respects `prefers-reduced-motion` accessibility setting
- Dark theme

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Jhonmarkseno/personal-portfolio.git
   ```
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Edit the text in `index.html` to update personal details and project links.

No installation or build step is needed.

## Deployment

This site is deployed with **GitHub Pages** from the `main` branch (root folder).

- Repository: https://github.com/Jhonmarkseno/personal-portfolio
- Live site: https://jhonmarkseno.github.io/personal-portfolio/

To update the live site, commit your changes and push to `main`; GitHub Pages redeploys automatically.
